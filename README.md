# Prueba de Fondeo

Simulador gratuito para traders de prop firms: ¿con qué probabilidad pasarías tu challenge, con qué
riesgo por operación, y cuánto de eso es suerte?

- Sitio: se publica en GitHub Pages desde `main`.
- Todo se calcula en el navegador; no se guardan datos.
- Pruebas: `node --test tests/*.test.mjs`.

Herramienta independiente, sin afiliación con ninguna prop firm. No es asesoría financiera.
